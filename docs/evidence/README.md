# Legacy prototype evidence

This directory contains the **old two-class YOLOv8n prototype** used during the
first review. It is kept for before/after comparison and should not be quoted as
the current result.

The current six-class model card, held-out metrics, PR/F1 curves and confusion
matrices are in:

- [`ai/evidence/README.md`](../../ai/evidence/README.md)
- [`ai/evidence/metrics.json`](../../ai/evidence/metrics.json)

Legacy prototype: mAP@50 0.5886, mAP@50–95 0.4029.
