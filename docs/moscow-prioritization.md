# MoSCoW Prioritization

| Priority | Features |
|----------|----------|
| **Must Have** | User Registration, Secure Login, BCrypt Password Encryption, JWT Authentication, Protected REST APIs, PostgreSQL Integration, Spring Boot Backend, React Frontend, AWS EC2 Deployment |
| **Should Have** | User Profile Management, Responsive UI, Docker Support, Dashboard, Unit Testing |
| **Could Have** | AI Login Anomaly Detection, AI Activity Monitoring, Smart Security Recommendations, AI Dashboard Insights, CI/CD Pipeline, Delete User Account |
| **Won't Have (Current Release)** | Multi-factor Authentication, Email Notifications, Mobile Application, Real-time AI Predictions, Third-party Integrations |
